## Plugins Evaluated

### WS Forms
- Cody is familiar with it and has used it before
- Has conditional logic built in
- Floated as a potential step-wizard to house the configurator flow
- **Verdict:** Can't replicate the "ask once, apply everywhere" logic — not a replacement for the React app

### Chamevo (chamevo.com)
- Visual product configurator — drag/drop logos/images onto product photos
- Flat monthly pricing (not per-checkout or % of sales)
- Has 3D model support (shirts, bottles, etc.)
- **Potential role:** Plug into the existing React app to handle the visual customization side (logo-on-product rendering), not to replace the flow
- **Action:** Jerad to research integration effort and API key requirements

### Fancy Product Configurator (WooCommerce plugin)
- One of ~6 WooCommerce configurator plugins with strong ratings
- Flat pricing model — no per-checkout or revenue-share fees
- More visually polished than older-style configurators
- **Status:** On the radar as an alternative to Chamevo for the visual piece

---

## Key Decisions

### Stick with the React App — Confirmed Again
The original plan stands. No plugin can replicate the core UX differentiator:
- Ask questions once (logo, quantity, kids' names, etc.) and apply across all products automatically
- Every other solution requires jumping back and forth, repeating selections per item
- Multiple plugin integrations also tend to get slow and clunky as they pull from multiple databases

### Chamevo / Plugin Role — Visual Only
If any plugin gets integrated, it's only to handle the **visual logo-on-product rendering** inside the existing app — not to replace the step-wizard flow or the "ask once" logic.

### Ship Fast, Iterate Later
- Get it out the door, use early customers as live beta testers
- Collect feedback for 2–3 months, then refactor
- Not going to chase every feature request on the fly
- Refactoring to a better visual configurator later is an option once the core flow is proven
